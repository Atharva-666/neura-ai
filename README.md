✨ About

Neura AI is a lightweight and responsive AI chatbot that brings the power of Google Gemini to a simple web interface.

It uses a Node.js + Express backend to securely communicate with the Gemini API while keeping the API key on the server side.

«💡 Simple interface. Powerful AI. Easy to use.»

---

🚀 Features

- 🤖 Google Gemini AI — Intelligent AI-powered conversations
- 💬 Real-time Chat — Send messages and receive AI responses
- ⚡ Fast Backend — Powered by Express.js
- 🔐 Secure API Key — Credentials managed using environment variables
- 🌐 Web Interface — Clean and simple browser-based UI
- 📱 Responsive Design — Works across different screen sizes
- 🧩 Easy Setup — Get started in just a few commands

⚙️ Installation

1️⃣ Clone the repository

git clone https://github.com/kaushaltekade/neura-ai.git

2️⃣ Enter the project

cd neura-ai

3️⃣ Install dependencies

npm install

4️⃣ Configure Gemini API

Create a ".env" file in the root directory:

GEMINI_API_KEY=your_gemini_api_key

«🔒 Never share or commit your API key.»

5️⃣ Start Neura AI

npm start

Open:

http://localhost:3000

---

🔑 API

Neura AI communicates with the backend through:

POST /message

Request

{
  "message": "Hello Neura AI!"
}

Response

{
  "reply": "Hello! How can I help you today?"
}
